## 🧩 Notable Projects

<b>⚙️ Distributed Microservice Backend Platform</b>

<ul>
<li>Architected a 5-service Spring Boot microservices platform using REST for client-facing APIs, gRPC over HTTP/2 for low-latency internal communication, and Kafka for asynchronous event-driven messaging.</li>
<li>Added a Redis caching layer with 10-minute TTL on read-heavy endpoints, reducing repeated database queries by ~40% and improving read throughput.</li>
<li>Deployed and orchestrated all 5 services on Kubernetes, configuring pods and horizontal scaling for reliable production-like operation.</li>
</ul>

🔗 <a href="https://github.com/rxhuljoshi10/Distributed-Microservice-Backend-Platform">Repository</a>

<br>

<b>🤖 Sentinel AI — Autonomous Incident Investigation Agent</b>

<ul>
<li>Built an autonomous incident investigation platform using specialized AI agents and tools to analyze logs, incident descriptions, and historical context, generating structured Root Cause Analysis (RCA) reports.</li>
<li>Designed a 5-agent LangGraph workflow comprising Planning, Log Analysis, RAG Retrieval, Service Memory, and RCA Synthesis for structured multi-step investigation.</li>
<li>Implemented RAG with ChromaDB for semantic retrieval of historical incidents and built an automated RCA evaluation framework using semantic similarity metrics and LLM-as-a-Judge scoring.</li>
<li>Shipped a full-stack dashboard with Next.js, Redis-backed sessions, JWT authentication, and Docker Compose for one-command local deployment.</li>
</ul>

🔗 <a href="https://github.com/rxhuljoshi10/Sentinel-AI-Investigation-Engine">Repository</a>
